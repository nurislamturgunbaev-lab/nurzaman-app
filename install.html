Объекты, АВР, договоры, 3D и отчёты — как приложение на телефоне и компьютере
Открыть в браузере
iPhone / iPad1. Откройте эту страницу в Safari.
2. Нажмите «Поделиться» ⬆ внизу экрана.
3. Выберите «На экран „Домой“» → «Добавить».
AndroidЕсли кнопка не сработала: Chrome → меню ⋮ → «Установить приложение» (или «Добавить на гл. экран»).
Компьютер (Chrome / Edge)Если кнопка не сработала: значок установки ⊕ справа в адресной строке или меню ⋮ → «Установить Nurzaman».
Откройте на телефоне — наведите камеру:
При первом запуске приложение попросит ссылку с ключом — её выдаёт администратор.
